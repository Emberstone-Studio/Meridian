# Tasker

This `.tasker/` folder holds Tasker's board, roles, chats, and task data for this
workspace, created and managed by the Tasker VS Code extension. Safe to commit or
to gitignore — controlled by the "Commit Tasker to Git" setting.

Related locations:

- `~/.tasker/` — global Tasker home: settings, credentials, and machine-local
  per-workspace runtime state (agent PIDs, session maps, run transcripts). Never
  committed.
- `~/.vscode/extensions/emberstone-studio.tasker-<version>/` — the installed
  extension (its bundled server and docs).

Learn more: https://github.com/Emberstone-Studio/Tasker
