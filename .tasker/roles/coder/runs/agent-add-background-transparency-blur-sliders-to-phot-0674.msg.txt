Description:
Add two sliders (transparency and blur) to the settings Appearance panel, nested under the "Photos" background section only — they should not apply to or appear for Colors & Gradients backgrounds.

Behavior:
- Both sliders affect only photo backgrounds; hidden/disabled when a color/gradient background is active.
- Transparency fades the photo toward the already-sampled accent color (the same color canvas-sampled for the UI accent), not a fixed #fff/#000 — this keeps background, accent, and fade all derived from one source. Keep black/white (light mode → #fff, dark mode → #000) as a manual fallback/toggle in case the sampled-color fade looks muddy at high transparency — designer wants to eyeball both before finalizing.
- Blur uses standard CSS filter: blur().
- Both sliders must preview live as the user drags — no reopening settings to see the result.
- The accent-color canvas sampling itself should run once when the photo is selected/changed, then be cached — do NOT re-run pixel sampling on every slider tick. The sliders only interpolate opacity/blur against the cached sampled value, which is cheap and fine to update live.
- Place the two sliders directly under the existing "Photos" section in the settings modal, visually nested/indented so it's clear they're modifiers of the current photo choice, not a standalone feature.
