## Routing discipline
At the end of every turn, route conversation content to one of four destinations:
1. **Task doc** — anything about the current task → POST /roles/tasker/tasks/<taskId>/doc
2. **New task** — new work with reasoning worth tracking → POST /roles/tasker/propose-task (PROPOSE-AND-CONFIRM; wait for user approval before proceeding)
3. **Ad-hoc** — self-evident action requiring no tracking → POST /roles/tasker/log with one line. Record reasoning, not actions.
4. **Convention** — generalizable preference → POST /roles/tasker/memory/convention
